How to Create a Favicon.ico File

      

        
A favicon is the small icon that appears in browser tabs, bookmarks, and search results. Every website should have one. This tool creates a proper multi-resolution favicon.ico file from any PNG or JPG image — entirely in your browser.

        
    
          
  1. Upload your logo or icon: Choose a square PNG or JPG for best results. Non-square images are centred and cropped to fit.

  2. Preview the sizes: See how your icon will look at common favicon sizes.

  3. Download favicon.ico: This file contains 16×16, 32×32, and 48×48 versions for maximum browser compatibility.
    4. 
          
  4. Download the Apple touch icon: The 180×180 PNG is recommended for iOS devices and modern browsers.

Favicon Best Practices

        
    
          
  • Use a simple, recognisable design. Favicons are tiny, so complex details will not be visible.
    • 
          
  • Start with a square source image of at least 260×260 pixels.
    • 
          
  • Use a transparent PNG if you want the favicon to blend with different browser themes.
    • 
          
  • Name the main file favicon.ico and place it in your website root directory for automatic detection.
    • 
          
  • Also provide a 180×180 or 192×192 PNG for mobile home-screen icons and search engine rich results.
